WeChatMosaic 马赛克工具 — 使用说明
====================================

一个 Windows 桌面隐私遮挡小工具：用微信聊天时，盖住不想被旁人看到的区域。
纯本地运行，不联网、不收集数据。默认智能跟随目标窗口，可切换多种遮挡模式。

【运行环境】
- Windows 10 / 11（64 位）
- 无需安装，.NET Framework 4.x 系统自带
- 本说明随发布包更新，不单独标识程序版本号；程序版本以 GitHub Release 为准

【怎么开始】
1. 解压后双击 WeChatMosaic.exe
2. 无配置文件，或配置中的区域列表为空时，会出现两块示例遮挡 + 一个控制窗口
3. 把遮挡块拖到要遮住的位置（会话列表、聊天内容等）
4. 拖动右下角黄色角标调整大小
5. 在遮挡块上点【右键】可换样式、调不透明度、删除

【样式说明】（遮挡块上右键切换）
- 毛玻璃（推荐）：采样边缘外侧颜色 + 磨砂噪点，隐约见影、读不清字
- 模糊：深色底 + 噪点；马赛克：棋盘格；纯色：默认深灰
- 不透明度：右键菜单里的滑块，实时调整
- 纯色颜色：界面暂无取色器，可在配置的 color 字段修改（ARGB，如 #FF202020）
- 毛玻璃颜色不合时，可用右键「重新取色（毛玻璃用）」

【常用操作】
- 移动遮挡块：鼠标穿透关闭时，按住遮挡块拖动
- 调整大小：拖动右下角黄色角标
- 鼠标穿透：主窗口「🖱 鼠标穿透」；开=点击直达下层应用，关=可拖动编辑
- 一键遮挡/还原：按热键（默认 Shift + |，可在控制窗口自定义）
- 跟随微信：默认智能模式；微信可见且当前使用时遮挡，非置顶时切走自动收起
- 目标窗口置顶：切到其它程序仍保持遮挡
- 开机自启：控制窗口可开关（写当前用户启动项）
- 退出程序：右键右下角托盘图标 → 退出；点窗口 X 只是隐藏到托盘

【配置与升级】
- 配置保存在 exe 同目录的 mosaic-config.json，包含遮挡区域、样式、热键和开关状态
- 样式、透明度、尺寸调整会防抖保存；正常退出时统一保存当前配置
- 升级时保留原配置文件即可；不要删除仍有用的配置
- 不要同时运行改名试用版和正式版，它们可能共用一份配置

【提示】
- 纯色颜色与跟随目标进程等高级选项可按需调整；不确定时保留默认值
- 公众号文章 / 内置浏览器窗口是否被识别为跟随目标，取决于微信版本；当前未按窗口类型排除，请实测确认
- 部分安全软件可能提示，程序使用了全局热键、窗口置顶等系统接口
- 发布包不含个人配置，解压后无配置或区域列表为空时会生成示例遮挡
